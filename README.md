# Web Timer

設定したWebサイトを開いてからの経過時間を計測し、15分ごとにページ上へ通知するChrome拡張機能です。

## インストール

1. Chromeで `chrome://extensions` を開きます。
2. 右上の「デベロッパー モード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」を選び、このフォルダーを指定します。
4. 拡張機能のポップアップには、初回設定としてYouTube、X、Instagram、Facebook、TikTok、Threads、Reddit、Snapchat、Pinterest、LinkedIn、Twitchが入力されています。必要に応じて編集し、「保存」を押してください。
5. 表示された確認画面で、対象ドメインへのアクセスを許可します。
6. 設定後、すでに開いている対象サイトで計測が始まらない場合は、そのページを再読み込みしてください。

入力したドメインのサブドメインも対象になります。すでに開いている対象サイトにも設定保存後から適用されます。計測時間はタブごとに記録され、ページを再読み込みしてもタブを閉じるまでは引き継がれます。

通知が表示されている間は、そのWebページ上のクリック、キー入力、スクロールをブロックします。「閉じる」を押すと操作を再開できます。Chromeのアドレスバーやタブ操作、ブラウザーが予約しているショートカットは拡張機能からブロックできません。

拡張機能のアイコンをクリックすると、現在のタブを開いてからの経過時間を `HH:MM:SS` 形式でリアルタイムに確認できます。
